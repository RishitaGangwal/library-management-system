# 📚 Library Management System

A Java console-based Library Management System that allows users to add, view, issue, and return books in a simple and structured way.

This project is designed to understand basic Object-Oriented Programming (OOP) concepts in Java and how real-world library systems work.

---

## 🚀 Features

- Add new books to the library
- View all available books
- Issue books to users
- Return issued books
- Track availability of books
- Simple console-based menu system

---

## 🧠 Why this project

Libraries need a proper system to manage books efficiently.

This project helps in understanding:
- How data is managed in applications
- Basic OOP concepts like classes and objects
- State changes (available → issued → returned)
- Console-based user interaction

---

## 🏗️ Tech Stack

- Java (Core Java)
- Object-Oriented Programming (OOP)
- Console-based Application
- Scanner class for user input
